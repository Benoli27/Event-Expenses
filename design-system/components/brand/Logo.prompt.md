Renders the official Scouts logotype — use it wherever the brand mark appears, never re-typeset "Scouts" in text.

```jsx
<Logo variant="stack" tone="purple" personalisation="8th Sutton" height={80} />
```

Variants: `stack` (preferred), `horizontal` (tight spaces), `wordmark`, `fleur` (mark alone — only when the Scout context is already clear). Tones are single-colour only: purple on white, white on purple/black/photography, black on white. `personalisation` sets the Group name in Nunito Sans Extra Bold below the mark. Minimum sizes: horizontal 40mm, stack 30mm when personalised.
